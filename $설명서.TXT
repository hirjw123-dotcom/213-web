# 선행 설치
- nodejs: https://nodejs.org/ko/download (하단 'Windows 설치 프로그램 (.msi)')
- codex: https://openai.com/ko-KR/codex/ (하단 'Windows 버전 다운로드')

# 실행 방법(첫 실행일 경우 npm i 실행)
1. npm run dev
2. http://localhost:5173/ 접속

# 개발 방법
1. codex 설치
- https://openai.com/ko-KR/codex/

2. gpt 5.6 sol - Extra high(매우높음) 사용
- ultra 사용 금지(맥락 꼬임 가능성)

# 배포 방법
1. 중앙 컴퓨터에 있는 1대대 홈페이지 html 파일의 용량을 확인한다.
- 9월 1일 기준 (1,583,087 바이트) 일 것이다.

2. npm run build 실행

3. $sample 폴더에 있는 '26.07.13.html-비교본' 파일을 $publish 폴더로 복사한다.

4. npm run update를 실행한다.

5. print.html을 실행하고 인쇄하기를 누른다.
- PDF로 저장.
- 여백: 맞춤
-- 위: 10.5mm
-- 좌/우: 7mm
-- 하단: 3mm

6. 프린트물을 들고가서 중앙 PC에서 스캔한다.
- 흑백 / 흑백경계값 70
- 하단에 PDF/JPEG 이런거말고, '찾기 가능한 문서(PDF)' 선택

7. 스캔 문서들을 순차적으로 실행해서 복사한다. 
- CTRL+C가 안먹히니 전체 선택 - 우클릭 - 복사로 해야한다.
- 메모장에 넣는다.

8. 메모장 내용을 복사해서 dec.html 에 넣는다.
- 이때 ocr 스캔 오류로 잘못 인식된 문자가 많은데, compare.html을 보고 라인 위치 등을 비교해서 쉽게 고칠 수 있다.

9. 성공하면 우측에 복호화된 json 값이 뜨는데, 이걸 메모장에 넣고 저장한다.
- 저장할때는 확장자를 json으로해야한다. 파일명은 무관.
- txt로하면 탁스 암호화되어버려서 복호화에 사용불가.

10. update.html에 이전버전의 html과 json파일을 넣고 업데이트를 한다.

11. 업데이트된 파일이 다운로드되면, 원본은 따로 백업한다.
- 그리고 복사본을 D드라이브 213web폴더에 넣는다.
- 그리고 D드라이브에있는 바로가기 링크를 신규 파일로 연결해준다.


## **중요** 정리
- $publish 폴더에있는 'final.html-비교본'과 'final.html'은 이름을 바꿔서 $history에 보관한다.
